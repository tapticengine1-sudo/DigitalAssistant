# Changelog: Рефакторинг Ptako Helper

## ✅ Выполненные задачи

### 1. Голосовой ввод Hold-to-Talk ✓
- **Исправлена логика HoldToTalk**: добавлен callback `onPartialText` для отображения промежуточных результатов распознавания в реальном времени
- **Визуальная индикация**: при удержании кнопки микрофона текст распознавания показывается прямо в поле ввода
- **Автоотправка**: при отпускании кнопки текст автоматически отправляется в чат
- **Стабильность**: улучшена обработка ошибок и перезапуск распознавания при удержании

### 2. Умные заголовки чатов ✓
- **Автогенерация заголовков**: при первом сообщении в чате автоматически создается краткий заголовок из 2-3 значимых слов
- **Замена стандартных**: убраны "Новый диалог" и "Оверлей", вместо них используется контент первого сообщения
- **Логика**: фильтруются слова длиной > 2 символов, берутся первые 3 слова (макс. 40 символов)

### 3. Исправление цвета в истории ✓
- **Белый текст на темном**: заголовки диалогов теперь используют `@color/ptako_text` (#FFE8EEF8)
- **Читаемость**: подзаголовки используют `@color/ptako_text_muted` (#FF9AA8C2)

### 4. Меню вложений в оверлее ✓
- **Три варианта**: при клике на скрепку показывается диалог с опциями: Камера, Галерея, Файл
- **Реализовано в MainActivity и OverlayActivity**: единообразный UX

### 5. Встроенный экран камеры ✓
- **CameraActivity**: кастомный интерфейс съемки с использованием CameraX API
- **Функции**:
  - Предпросмотр камеры в реальном времени
  - Кнопка захвата (большой круг)
  - Предпросмотр сделанного фото
  - Кнопки "Переснять" и "Готово"
  - Автоматическое закрытие после подтверждения
- **Интеграция**: фото мгновенно прикрепляется к текущему сообщению

### 6. Компактные иконки вложений ✓
- **Мини-иконка вместо текста**: в ChatAdapter вложения теперь отображаются как маленькая иконка (24dp)
- **Визуал**: цветной полупрозрачный квадратик с иконкой галереи
- **Стиль Gemini**: компактно и не отвлекает от текста сообщения

### 7. Встроенная мини-галерея ✓
- **GalleryActivity**: внутренний интерфейс выбора фотографий из памяти устройства
- **Функции**:
  - Сетка 3x3 с превью всех фотографий
  - Сортировка по дате (новые сверху)
  - Чтение из MediaStore (системная база медиафайлов)
  - Простой тап для выбора
- **Стиль Telegram**: удобный, быстрый, нативный опыт
