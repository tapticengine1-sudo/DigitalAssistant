# Changelog: Рефакторинг Ptako Helper

## ✅ Выполненные задачи

### 1. Голосовой ввод Hold-to-Talk ✓
- **Исправлена логика HoldToTalk**: добавлен callback `onPartialText` для отображения промежуточных результатов распознавания в реальном времени
- **Визуальная индикация**: при удержании кнопки микрофона текст распознавания показывается прямо в поле ввода
- **Автоотправка**: при отпускании кнопки текст автоматически отправляется в чат
- **Стабильность**: улучшена обработка ошибок и перезапуск распознавания при удержании

### 2. Умные заголовки чатов ✓
- **Автогенерация заголовков**: при первом сообщении в чате автоматически создается краткий заголовок из 2-3 значимых слов
- **Замена стандартных**: убраны "Новый диалог" и "Оверлей", вместо них используется контент первого сообщения
- **Логика**: фильтруются слова длиной > 2 символов, берутся первые 3 слова (макс. 40 символов)

### 3. Исправление цвета в истории ✓
- **Белый текст на темном**: заголовки диалогов теперь используют `@color/ptako_text` (#FFE8EEF8)
- **Читаемость**: подзаголовки используют `@color/ptako_text_muted` (#FF9AA8C2)

### 4. Меню вложений в оверлее ✓
- **Три варианта**: при клике на скрепку показывается диалог с опциями: Камера, Галерея, Файл
- **Реализовано в MainActivity и OverlayActivity**: единообразный UX

### 5. Встроенный экран камеры ✓
- **CameraActivity**: кастомный интерфейс съемки с использованием CameraX API
- **Функции**:
  - Предпросмотр камеры в реальном времени
  - Кнопка захвата (большой круг)
  - Предпросмотр сделанного фото
  - Кнопки "Переснять" и "Готово"
  - Автоматическое закрытие после подтверждения
- **Интеграция**: фото мгновенно прикрепляется к текущему сообщению

### 6. Компактные иконки вложений ✓
- **Мини-иконка вместо текста**: в ChatAdapter вложения теперь отображаются как маленькая иконка (24dp)
- **Визуал**: цветной полупрозрачный квадратик с иконкой галереи
- **Стиль Gemini**: компактно и не отвлекает от текста сообщения

### 7. Встроенная мини-галерея ✓
- **GalleryActivity**: внутренний интерфейс выбора фотографий из памяти устройства
- **Функции**:
  - Сетка 3x3 с превью всех фотографий
  - Сортировка по дате (новые сверху)
  - Чтение из MediaStore (системная база медиафайлов)
  - Простой тап для выбора
- **Стиль Telegram**: удобный, быстрый, нативный опыт

## 🔄 Обновление от 25.10.2026: Полный рефакторинг и ребрендинг

### 1. Ребрендинг приложения ✓
- **Название**: Приложение переименовано в «Ptako Helper»
- **strings.xml**: обновлен app_name на "Ptako Helper"
- **Иконка**: создана новая векторная иконка с буквой "P" в синей цветовой схеме
- **UI**: все заголовки и упоминания обновлены на новое название

### 2. Тёмная тема и синий акцент ✓
- **Принудительная тёмная тема**: применена для всего приложения включая оверлей
- **Цветовая схема**:
  - Фон: `#FF0D1117` (темно-серый)
  - Поверхности: `#FF161B22` (немного светлее)
  - Текст: `#FFE8EEF8` (светлый)
  - Акцент: `#FF1E90FF` (глубокий синий)
  - Мягкий синий: `#FF64B5F6`
  - Обводка: `#FF30363D`
- **themes.xml**: обновлены основная и оверлейная темы с новыми цветами

### 3. Обновленный главный экран (MainActivity) ✓
- **Верхняя панель**:
  - Слева: кнопка «☰» (История и поиск)
  - По центру: название «Ptako Helper»
  - Справа: кнопка «+» (Новый чат) и кнопка «⚙» (Настройки)
- **Приветственное сообщение**: полностью убрано с главного экрана
- **Нижняя панель ввода**:
  - Плейсхолдер: "Пишите..."
  - Слева: иконка скрепки 📎 (вложения)
  - Справа: кнопка микрофона 🎤 (Hold-to-Talk) и кнопка отправки ➤

### 4. Переход на Hold-to-Talk (как в DeepSeek) ✓
- **Полное удаление hotword сервиса**:
  - Удалены все упоминания кодового слова «Джарвис»
  - HotwordService, SpeechRecognizerHotwordEngine, BootReceiver - не найдены в проекте (уже удалены)
  - AndroidManifest.xml проверен - фоновых сервисов нет
- **Механика Hold-to-Talk**:
  - Удерживание кнопки → запись и STT в реальном времени
  - Отпускание кнопки → автоматическая отправка распознанного текста
  - Визуальная индикация: волновая форма, изменение иконки на ⏸ во время записи
  - Кнопка Send меняет функцию: во время записи отправляет голосовой ввод мгновенно

### 5. Обновление оверлея (OverlayActivity) ✓
- **Идентичный интерфейс**: те же элементы что и на главном экране
- **Hold-to-Talk**: полностью интегрирован с HoldToTalk.kt
- **Цветовая схема**: применена темная тема с синим акцентом
- **Автозапуск**: микрофон автоматически активируется при вызове через hotword или intent с флагом EXTRA_START_VOICE

### 6. Технические улучшения ✓
- **HoldToTalk.kt**:
  - Метод `stopAndSend()` для мгновенной отправки при клике на Send
  - Улучшена стабильность распознавания
  - Поддержка автоматического запуска через `startListeningAuto()`
- **Вычищены неиспользуемые импорты**
- **Проверка на ошибки компиляции**: код готов к сборке
