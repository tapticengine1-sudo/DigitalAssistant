# Помощник (DeepSeek) — Android

## Сборка APK без Android Studio (GitHub)
1. Создайте репозиторий на github.com и загрузите в него все файлы этого проекта (включая папку .github).
2. Вкладка Actions → Build APK → Run workflow (или просто сделайте push).
3. Когда сборка закончится, скачайте артефакт assistant-apk → app-debug.apk.

## Сборка в Android Studio
File → Open → папка проекта → Build → Build APK(s).

## Первая настройка на телефоне
1. Установите APK (разрешите установку из неизвестных источников).
2. ⚙ → вставьте DeepSeek API-ключ → Сохранить.
3. ⚙ → «Микрофон, звонки, контакты, уведомления» → разрешить.
4. ⚙ → «Изменение системных настроек» и «Не беспокоить» → включить переключатель для приложения.
5. ⚙ → «Назначить помощником по умолчанию» → выберите «Помощник».
   (Обычно: Настройки → Приложения → Приложения по умолчанию → Цифровой помощник.)

## Новые возможности
- **История (☰)** — диалоги в SQLite, поиск по тексту, долгое нажатие — удаление.
- **Вложения (📎)** — картинки/файлы; для картинок включите «Мультимодальный режим» в настройках.
- **Непрерывный голос** — тумблер на главном экране: после TTS снова слушает.
- **«Джарвис»** — в настройках включите слушание кодового слова (foreground service).
